# ☁️ Computação em Nuvem com Azure Cloud

A **computação em nuvem** é um modelo que fornece acesso a recursos de TI sob demanda pela internet, com pagamento baseado no uso. A **Microsoft Azure** é uma das principais plataformas de nuvem, oferecendo uma ampla gama de serviços para empresas e desenvolvedores.

---

## 🚀 Principais Características da Azure Cloud

- 💡 **Serviços sob demanda**: IaaS, PaaS e SaaS.
- 📈 **Escalabilidade automática**: Recursos aumentam ou diminuem conforme a necessidade.
- 🌍 **Alta disponibilidade**: Infraestrutura global com data centers distribuídos.
- 🔐 **Segurança**: Criptografia, controle de acesso e conformidade com GDPR, LGPD, ISO etc.
- 💸 **Modelo de pagamento flexível**: Pague apenas pelo que usar.

---

## 🧰 Serviços Comuns da Azure

| Serviço                  | Descrição                                                    |
|--------------------------|--------------------------------------------------------------|
| **Azure Virtual Machines** | Hospedagem de máquinas virtuais (servidores)                |
| **Azure App Service**      | Implantação e escalonamento de apps web                    |
| **Azure SQL Database**     | Banco de dados relacional como serviço (DBaaS)             |
| **Azure Blob Storage**     | Armazenamento de objetos (imagens, vídeos, arquivos)       |
| **Azure Active Directory** | Gerenciamento de identidades e autenticação                |
| **Azure Kubernetes Service** | Orquestração de contêineres com Kubernetes               |
| **Azure Functions**        | Execução de código serverless (sem servidor)              |

---

## ✅ Benefícios da Azure Cloud

- 📉 Redução de custos com infraestrutura física
- ⚙️ Agilidade na implantação de aplicações
- 🔄 Backup automático e confiabilidade
- 🔗 Integração com ferramentas Microsoft (Office 365, Power BI, etc.)
- 🤖 Suporte a tecnologias modernas: **IA, Machine Learning, Big Data, IoT**
